Accessibility statement

Building for more ways of using the web

DeAddict aims to make the prototype understandable and operable with keyboard navigation, screen readers, zoom, reduced-motion preferences, and small screens. This is an ongoing engineering goal, not a certification claim.

Current accessibility features

  • Skip links to main content
  • Visible keyboard focus styles
  • Semantic headings, landmarks, buttons, and links
  • Mobile navigation with Escape-key support and focus containment
  • Accordion controls with expanded state and controlled-panel relationships
  • Explicit selection states on check-in and onboarding buttons
  • Error messages announced with alert semantics
  • Reduced-motion support through system preferences
  • Responsive layouts for narrow screens and browser zoom
  • Text alternatives or hidden labels for functional icons

Target

The project aims toward WCAG 2.2 Level AA where practical. Automated checks and browser screenshots help detect some problems, but they do not replace manual keyboard, screen-reader, contrast, zoom, language, and cognitive-accessibility testing.

Known limitations

  • The prototype has not completed independent accessibility testing.
  • Some visual illustrations are decorative and may not provide an equivalent detailed description.
  • External helpline and GitHub pages follow their own accessibility practices.
  • Language selection, localization, captions, audio alternatives, and simplified-reading modes are not implemented.
  • The current sample dashboard uses generated mobile navigation that will be moved into permanent source structure in a later refactor.

Using the prototype

You can navigate interactive controls with Tab and Shift+Tab, activate buttons and links with Enter or Space as supported by the browser, close open mobile menus with Escape, and enlarge the page using browser zoom.

Report a problem

Technical accessibility problems may be reported through the public GitHub issue tracker. Describe the page, browser, device, assistive technology, and expected behavior, but do not include personal health, recovery, or identifying information.
